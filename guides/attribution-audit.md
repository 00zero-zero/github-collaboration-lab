# Contributor attribution audit

Before publishing collaborative work, verify both the primary author and any genuine co-authors.

Inspect the final commit metadata, confirm every author email is linked to the intended GitHub profile, and verify co-author trailers use the canonical format. After pushing, inspect the GitHub commit page or API author mapping.

Do not infer authorship from who pushed the branch. Transport authentication establishes who had permission to upload objects; commit metadata establishes attribution.

An attribution audit is especially valuable on machines that host several GitHub identities.
